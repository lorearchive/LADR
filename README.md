## About the reader

*Lore Archive's Dialogue Reader for Blue Archive*, often shortened to just **LADR**, is an online, web-based text story viewer for Blue Archive built from the ground up. It is written primarily in TypeScript and JavaScript, with the second major release of LADR using SvelteKit.


This is my first big project which uses git and GitHub, and you may find me figuring things out by poking at everything.
